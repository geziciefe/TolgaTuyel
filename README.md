# Tolga Tüyel — Sanatçı Sitesi

## Çalıştırma

```bash
npm install
npm run dev
```

Terminalin verdiği yerel bağlantıyı tarayıcıda aç.

## Fotoğraf ekleme

- Ana sayfa fotoğrafını `public/images` klasörüne koy.
- Ardından `src/pages/index.astro` dosyasındaki `.hero-photo-placeholder` alanına bir `background-image` ekle.
- Galeri fotoğraflarını aynı klasöre atıp `.gallery-placeholder` alanları yerine `img` kullanabilirsin.

Sosyal medya bağlantıları ve YouTube videoları `src/pages/index.astro` içinden düzenlenebilir.
